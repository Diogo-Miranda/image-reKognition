# image-reKognition
Testing image rekognition tests

# Step-by-step guide

1. Create a virtual environment
```
python3 -m venv venv
```

2. Activate the virtual environment

``` 
source venv/bin/activate
```

3. Install the dependencies
```
pip3 install -r requirements.txt
```

# For Deactivate the virtual environment

```
deactivate
```

# For run the main.py file

```
python3 main.py
```

# For configute the models

## Download all files
```
make
```

## Download all files
```
make download
```

## To remove downloaded files but keep directory
```
make clean
```

## To remove everything including directory
make clean-all
